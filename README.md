Entry for the make.fun bounty **"The One-Line Cat Joke That Lands"** — a single one-line cat joke, under 200 characters, with a setup and a turn that lands on first read.

## The joke

> I told my cat he's adopted; he blinked slowly, which in cat means either 'I already knew' or 'you're fired.'

## How to run

```bash
python3 main.py
```

This writes the joke to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output/entry.txt`). Python standard library only — no dependencies, no network, fully deterministic.
